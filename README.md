Forecast GTA VI's launch-day Twitch viewers hour by hour: a program that reads one case (hour 1's print, history, and 42 past big launches) and writes five quantiles of that hour's count for each of hours 2 to 24 of the release day, 2026-11-19 (UTC).

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
